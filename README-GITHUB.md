# Hundehilfe Hurghada – GitHub Pages Version

Diese Version wurde aus der gebündelten `index.html` entpackt und für GitHub Pages vorbereitet.

## Hochladen

1. Den kompletten Inhalt dieses Ordners in dein GitHub-Repository hochladen.
2. Wichtig: Nicht nur `index.html`, sondern auch den Ordner `assets/` hochladen.
3. In GitHub unter **Settings → Pages** den Branch `main` und den Ordner `/root` auswählen.
4. Danach die Seite neu laden.

## Was geändert wurde

- Bilder wurden als normale Dateien unter `assets/images/` gespeichert.
- Das JavaScript liegt unter `assets/js/site.js`.
- Der JavaScript-Start wurde repariert, damit die Inhalte nicht unsichtbar bleiben.
- Die extern verlinkten Unterseiten wurden als einfache Weiterleitungen angelegt, damit GitHub keine 404-Seiten zeigt.
- Eingebettete Font-Dateien wurden entfernt; die Seite nutzt Systemschriftarten.
